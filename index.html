Aster Vault

Private by design. Ready to recover. A local-first password manager for Windows.

Beta — not independently audited. This is an early, pre-1.0 release without a third-party security review. Use it for testing and for credentials you can afford to lose — not for your most important secrets.

Download for Windows View source

The installer is unsigned, so SmartScreen warns on first run — choose More info → Run anyway. A standalone recovery CLI is attached to each release.

What it does

  • Keeps secrets only on your device
  • Argon2id key derivation
  • AES-256-GCM authenticated encryption
  • No account, no cloud, no telemetry
  • Portable, encrypted backups
  • Recovery key, plus a recovery CLI
  • Password generator and reuse checks
  • Arabic and English interface

Honest about the limits

Read the threat model to see exactly what Aster Vault protects against — and what it does not. It has not been independently reviewed yet.
